# Notas de configuración

Diseños y planes de las piezas del escritorio que no se deducen leyendo el código.
Una carpeta por asunto; el código de cada asunto vive donde tiene que vivir
(`.config/omarchy/plugins/`, `.local/bin/`), no aquí.

| Carpeta | Qué es |
|---|---|
| `dashboard/` | Overlay de resumen (`SUPER + D`) y el servicio `marcos.metrics` que lo alimenta |

Cada carpeta lleva `design.md` (qué se decidió y por qué) y `plan.md` (cómo construirlo,
tarea a tarea).
